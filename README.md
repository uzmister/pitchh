# pitchh — NetCon Startup Pitch

[NetCon](http://netcon.uz) uchun **claymorphism** uslubidagi startup pitch deck.

- Ranglar: to‘q ko‘k + oq
- Harakat: o‘ngdan chapga slayd o‘tishi
- 12 slayd: muammo → yechim → mahsulot → bozor → biznes model → raqobat → traction → jamoa → maqsad

## Ishga tushirish

```bash
cd pitchh
python3 -m http.server 8080 --bind 0.0.0.0
```

So‘ng brauzerda `http://localhost:8080` ni oching.

## Boshqarish

- `←` / `Space` — keyingi slayd
- `→` — oldingi slayd
- Barmoq bilan suyuq (swipe)
- Pastdagi nuqtalar orqali istalgan slaydga o‘tish

## Fayllar

- `index.html` — butun presentatsiya (HTML + CSS + JS)
- `images/hero.jpg` — muqova rasmi
- `images/problem.jpg` — muammo slaydi rasmi
- `images/solution.jpg` — yechim slaydi rasmi

Jamoa slaydida (`index.html` → "JAMOA" bo‘limi) ism-familiyalarni o‘zgartiring.
